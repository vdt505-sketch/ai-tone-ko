# ai-tone-ko

한국어 글과 웹 화면에서 **"AI가 쓴 티"로 자주 지목되는 표면 패턴**을 세어 주는 작은 도구입니다.
설치할 것 없이 Node 하나로 돌아갑니다(의존성 0).

```bash
node ai-tone-ko.js 내글.md 홈페이지/ --detail
```

```
점수   이모지  체크 줄세우기  영어 라벨  em대시(—)  상투구  같은 끝말 3연속  3단 대칭 카드  그라데이션·글로우  파일
411    2       3              2          2          10      1                0              0                  examples/before.md
0      0       0              0          0          0       0                0              0                  examples/after.md
```

## 무엇을 세나
| 지표 | 왜 |
|---|---|
| 이모지 | 제목·카드마다 붙는 이모지는 생성물의 대표 신호 |
| 체크 줄세우기 | 같은 길이 항목을 ✓로 줄세우면 기계가 만든 표처럼 보임 |
| 영어 라벨 | 한국어 제목 위에 장식처럼 붙는 짧은 영어(About · Features …) |
| em대시(—) | 한국어 문장에 —를 자주 끼우면 번역투가 됨 |
| 상투구 | 혁신적 · 최적의 솔루션 · 원스톱 · 합리적인 가격 · 아이디어만 있어도 … |
| 같은 끝말 3연속 | "제공합니다. 제공합니다. 제공합니다." |
| 3단 대칭 카드 | 똑같은 3칸 카드 묶음(HTML) |
| 그라데이션·글로우 | 내용 대신 장식으로 고급감을 내려는 구성(HTML, 초점 링 제외) |

점수는 **1000자당 가중 밀도**입니다.

## 이 도구가 하지 않는 것
- 글이 좋은지, 사람이 썼는지를 **판정하지 않습니다.** 표면 패턴의 양만 잽니다.
- 점수가 0이어도 좋은 글이라는 뜻이 아닙니다. 마지막 판단은 소리 내어 읽어 보는 사람이 합니다.
- 점수는 글자 수로 나눈 값이라 문장을 늘리기만 해도 내려갑니다. 고친 전후는 `--compare`로 **원시 건수와 글자 수 변화**를 함께 보세요.

## 쓰는 법
```bash
node ai-tone-ko.js <파일·폴더...>               # 점수표 (.html .htm .md .txt)
node ai-tone-ko.js <...> --detail               # 어디에서 걸렸는지
node ai-tone-ko.js <...> --json > before.json   # 고치기 전 저장
node ai-tone-ko.js <...> --compare before.json  # 고친 뒤 비교: 실제 제거 / 희석 의심 / 패턴 증가
node --test test/                               # 시험
```
